# Unified portfolio go-live

Run these steps in order when the release branch has passed review. The user site will take over the old project site's URLs. A few minutes of downtime between deployments are acceptable. Keep the old repository available for recovery until the privacy link and legacy files pass step 5.

- [ ] **1. Select the publishing source.** Under **Build and deployment → Source**, select **GitHub Actions**. [User site Pages settings](https://github.com/falker47/falker47.github.io/settings/pages)
- [ ] **2. Publish the release.** Merge the reviewed `unify` branch into `main`. Wait for both the build and deploy jobs in `pages.yml` to succeed on the resulting commit. [Compare unify with main](https://github.com/falker47/falker47.github.io/compare/main...unify) · [Deploy Pages runs](https://github.com/falker47/falker47.github.io/actions/workflows/pages.yml)
- [ ] **3. Open every new route.** Verify HTTP 200 and the Italian and English views on the routes below. Open an unknown path and confirm HTTP 404, the language switch and both recovery links. Compare the indexable routes with the live sitemap. [Route declarations](../../src/routes.mjs) · [404 document](https://falker47.github.io/404.html) · [Unknown path](https://falker47.github.io/missing-go-live-check) · [Robots](https://falker47.github.io/robots.txt) · [Sitemap](https://falker47.github.io/sitemap.xml)
  - [Home](https://falker47.github.io/) · [Research](https://falker47.github.io/research/) · [Prof. Gecko](https://falker47.github.io/projects/prof-gecko/) · [Camaleonte](https://falker47.github.io/projects/camaleonte/) · [Uses](https://falker47.github.io/uses/)
  - [Social Viewer](https://falker47.github.io/projects/social-viewer/) · [Testing](https://falker47.github.io/projects/social-viewer/test/) · [Privacy](https://falker47.github.io/projects/social-viewer/privacy/)
- [ ] **4. Unpublish the old project site.** In the menu beside the live deployment, choose **Unpublish site**. Allow a few minutes for the user site to take over the mount. [Nexus-portfolio Pages settings](https://github.com/falker47/Nexus-portfolio/settings/pages) · [GitHub unpublishing instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/unpublishing-a-github-pages-site)
- [ ] **5. Check every old URL on the public origin.** Each source in the table must first return HTTP 200, then reach the listed destination with HTTP 200. Open the image URLs in the hash manifest, including names with spaces. Compare their downloaded bytes with the recorded SHA-256 values. Verify that a missing legacy project goes to the software tab. If the privacy page or another old URL fails, pause here. The unarchived project can be redeployed from its last working revision while the handover is investigated. [Redirect map](../../data/redirects.json) · [Full asset list and hashes](../../legacy/sha256.json) · [Original portrait](https://falker47.github.io/Nexus-portfolio/assets/profile/maurizio-falconi-falker47.webp) · [PNG logo](https://falker47.github.io/Nexus-portfolio/assets/branding/falkerlogo.png) · [WebP logo](https://falker47.github.io/Nexus-portfolio/assets/branding/falkerlogo.webp) · [Testing preview](https://falker47.github.io/Nexus-portfolio/assets/socialviewer/testers-preview.webp) · [Legacy project fallback](https://falker47.github.io/Nexus-portfolio/projects/missing-go-live-check)
- [ ] **6. Update Google Play.** Select Social Viewer (`io.github.falker47.socialviewer`), open **App content → Privacy policy**, set the URL below, save and submit the change if prompted. Check the published store listing after approval. [Play Console app content](https://play.google.com/console/app/app-content/summary) · [New privacy URL](https://falker47.github.io/projects/social-viewer/privacy/) · [Store listing](https://play.google.com/store/apps/details?id=io.github.falker47.socialviewer)
- [ ] **7. Update Social Viewer.** Point `PRIVACY_POLICY_URL` and the README’s privacy link at the new URL. Open the link from a QA build before shipping the app update. [SocialViewerApp.kt](https://github.com/falker47/SocialViewer/blob/main/app/src/main/java/io/github/falker47/socialviewer/ui/SocialViewerApp.kt) · [README privacy link](https://github.com/falker47/SocialViewer/blob/main/README.md#privacy) · [New privacy URL](https://falker47.github.io/projects/social-viewer/privacy/)
- [ ] **8. Replace the sitemap submission.** In the property that owns the old submission, remove `/Nexus-portfolio/sitemap.xml` from the Sitemaps report. Submit `https://falker47.github.io/sitemap.xml` in the user-site property and verify that Google can read it. [Search Console Sitemaps](https://search.google.com/search-console/sitemaps?resource_id=https%3A%2F%2Ffalker47.github.io%2F) · [Sitemaps report help](https://support.google.com/webmasters/answer/7451001)
- [ ] **9. Check Amazon Associates.** If the existing website entry does not cover the new recommendations page, add its URL to the account’s website list and save. [Associates website list](https://programma-affiliazione.amazon.it/home/account/profile/sitelist) · [Uses](https://falker47.github.io/uses/)
- [ ] **10. Archive the old repository.** Once the public URL checks pass and the external references are updated, use **Danger Zone → Archive this repository**. [Nexus-portfolio settings](https://github.com/falker47/Nexus-portfolio/settings)
- [ ] **11. Remove review evidence from main.** After sign-off, delete `_review/` through a cleanup PR targeting `main`. Wait for validation and the subsequent Pages deployment. Reopen the home page and privacy policy. [Review directory on main](https://github.com/falker47/falker47.github.io/tree/main/_review) · [Deploy Pages runs](https://github.com/falker47/falker47.github.io/actions/workflows/pages.yml)
