# Master home & technical sheets (V2)

- Direction V2 "Master home & technical sheets" replaces R1's "Sheets & Register". The home is the clean master home again; the projects live on their own page, `/projects/`, drawn as technical sheets ("tavole"). R1's register rows, filter chips, home tabs and sticky header are gone.
- Audience and first task: in one screen, recruiters, colleagues and users understand who Maurizio is (AI & Digital Innovation Specialist; software, modding, research, tutoring) and reach any project in at most 2 interactions (home → `/projects/` → sheet link).
- Tokens: bg #071525 with a 32 px grid (#9bdcff08 lines); surfaces #0b1d30 and #0d2338; text #f1f4f5, secondary #c9d7e2, muted #adbfce; accent #9bdcff; drawing stroke and sheet corner ticks #81bfe5; rules #304d65 and #1d3a52; Social Viewer product accent #49c7bb (its pages only).
- Type, self-hosted woff2 latin: Gelasio 400 and 400 italic for headings (metric-compatible with Georgia, so the hero keeps its metrics), IBM Plex Mono 400 for plate labels, spec keys and numbers, Poppins 600/700 for the person's name and the brand only, system sans for body. 4 px spacing grid. 999 px radius only for the single primary CTA.
- Heading scale outside the hero: page title (h1) ≤ 40 px; sheet titles 34 px desktop / 28 px mobile; group headings ≤ 30 px; every other heading ≤ 32 px.
- Motion: the hero pulse once per load; disclosure height animation; 150 ms opacity on tab change; all off with prefers-reduced-motion.
- Forbidden: emoji, decorative gradients or glow, chips, register rows, left-accent cards, more than one primary CTA per view, CDNs, third-party requests, video.
- Home "/": exactly the master home as F1 ported it: masthead (brand + IT/EN flags, not sticky, 64 px so the hero keeps F3's geometry) → hero (unchanged; single CTA "Esplora i miei progetti" → `/projects/`; identity card with GitHub, LinkedIn, Email as `#contatti`) → collapsible "Chi sono" (`#chi-sono`: about text, profile row with Ricerca → `/research/`, `#certificazioni` with 4 visible + "Mostra tutte (11)" + `<dialog>` viewer) → collapsible "Cosa faccio" (`#cosa-faccio`: the master's Software / Modding / Ricerca / Lezioni tabs and examples) → one-line signature footer.
- "Cosa faccio" figures come from data: app, game and tool counts from `data/projects.json` (→ `/projects/#app`, `#giochi`, `#strumenti`), papers from `data/research.json` (→ `/research/`), mods and unique downloads live from the Nexus snapshot, ratings from `data/tutoring.json`. "Tutti i progetti" → `/projects/`.
- Projects "/projects/": shared header, h1 "Progetti", one-line intro, a text index with counts (App · Giochi · Strumenti · Mod · Ricerca → `#app #giochi #strumenti #mod #ricerca`). One section per group; each project is an `<article class="tavola">` separated by a 1 px rule. Desktop (≥ 900 px): 7fr / 5fr grid, image side alternating. The image sits in a 16:10 sheet frame with four 2 px corner ticks, at most its largest native rendition. Text side: mono plate "Tav. NN" (#9bdcff), h2, a two-line description, spec table with 1 px rules (Tipo / Tecnologie / Dove), "Apri la scheda →" when a project page exists, otherwise "Apri ↗" to the demo, store or Nexus page, plus "GitHub ↗" when there is a repository. Mobile: image on top, plate, 28 px h2, description, spec table, one 44 px link. Order: the 14 software in data order inside their groups, the 3 mods, then Ringmin (→ `/research/`). Plate numbers follow this order and are reused on the project pages.
- Project pages (`/research/`, `/projects/prof-gecko/`, `/projects/camaleonte/`, `/projects/social-viewer/`, `/uses/`): shared header; breadcrumb "← Progetti" → `/projects/` ("← Home" on `/uses/`); a top sheet (framed image + plate + h1 + lead + spec table + actions); then short blocks under ruled headings. Social Viewer's tester page uses its framed path picker as the top sheet, so a tester sees the steps without scrolling; its privacy page keeps the original text byte for byte.
- Shared header everywhere except the home: brand · Home · Progetti · Ricerca · Chi sono (→ `/#chi-sono`) · IT|EN; it scrolls with the page and wraps to two rows on phones. Shared footer: name, handle, Email, GitHub, LinkedIn, ORCID and "Strumenti che uso" (`/uses/`).
- Languages: IT rendered by default, EN through the toggle on the same URL.
- Data: data/projects.json and data/mods.json (incl. `where` and, for mods, `kind` and `stack` for the spec table), data/certifications.json, data/tutoring.json, data/research.json, data/i18n/{it,en}.json. Counts are always computed, never typed.
